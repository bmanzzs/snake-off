Snake-Off

Six AI coding agents got the same one-shot prompt: build a 3D snake game. Three ran on a home server, three in the cloud. Play them blind, guess who made which, then reveal.

  • Needs a keyboard: arrow keys or WASD
  • Pick your favorite with ★
  • Guess the AI for each game
  • Hit Reveal when you're done
The prompt every agent got
Build a 3D Snake game in the snake folder. Use Three.js: install it with npm and load it from the folder, because your test browser has no internet. Make it look great: a 3D snake that moves smoothly and grows, an apple to eat, little touches like the apple spinning and bobbing and a burst of particles when it's eaten, a score, and a game-over screen with restart. Steer with the arrow keys or WASD. Plan it first, then build it in steps. After each step, open http://localhost:8000/snake/index.html in your browser, check the console for errors, take a screenshot and look at it, and fix anything that's wrong. Commit to git after each working step. When you're done, tell me what you built and how to play it.

No follow-ups, no hints, no human edits. Each agent could write files, run commands, open its own game in a browser and look at screenshots.

The contestants

  • Gemma 4 31B on Ollama, 4-bit (local)
  • Qwen 3.8 27B on a V100-tuned llama.cpp, 6-bit (local)
  • Inkling 2 Mini 26B on a V100-tuned llama.cpp, 4-bit (local)
  • Claude Sonnet 5.5

  • GPT-5.6 Terra (high)

The three local runs used open-weights models on a home NAS with two Tesla V100s, through the Hermes agent, in a sandbox with an offline browser. The cloud models ran in their own coding apps (Claude Code, Codex).
